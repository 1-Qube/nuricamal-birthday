# Happy 12th Birthday, Nuricamal! 🎨✨

A magical digital art gallery and interactive birthday celebration website created especially for **Nuricamal** on her **12th Birthday**.

> *"Today, the world is your canvas."*

---

## 🌟 Highlights & Features

1. **Awwwards-Inspired Visual Design**:
   - Warm handcrafted paper/linen aesthetic with organic watercolor splatters and painterly palettes.
   - Elegant typography pairing *Playfair Display*, *Caveat*, and *Plus Jakarta Sans*.
   - Floating stars, watercolor droplets, and subtle ambient animations.

2. **The Little Artist's Studio (Interactive Canvas)**:
   - Full painting canvas responsive to mouse and touch/stylus with high-DPI retina sharpness.
   - Smooth Bézier curve brush strokes.
   - 11 curated artist swatches + custom color picker (`🌈`).
   - Brush size slider (2px to 60px).
   - Eraser tool, Clear canvas, and instant **Save Masterpiece (PNG)** download.

3. **Her Little Art World (Exhibition Hall)**:
   - 6 museum-grade exhibition frames (ornate gilded gold & warm gallery oak with passe-partout matting).
   - Museum placards with artwork title, artist name, and year 2026.
   - Built-in photo mounting button on every frame so family can easily mount Nuricamal's real paintings directly in the browser!

4. **Birthday Surprise & Unfolding Letter**:
   - A secret letter with wax seal `N`, revealing the heartfelt birthday message:
     > *"Dear Nuricamal, never stop creating, dreaming, and filling the world with your colors. You have a special talent, and I hope your 12th year brings you endless happiness, inspiration, and beautiful adventures. Happy Birthday!"*

5. **Make a Wish (Interactive Cake & Candle)**:
   - Interactive birthday cake with a flickering flame.
   - Blowing out the flame triggers a rising smoke wisp, a celebratory wish message, and a vibrant shower of custom confetti!

6. **100% Pure Frontend (No Backend Required)**:
   - Built using only clean HTML5, CSS3, and vanilla JavaScript.
   - Zero dependencies, zero build steps, completely static and fast.

---

## 🚀 Running Locally

Simply double-click `index.html` to open it in any web browser, or serve it using any static server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js npx
npx serve .
```
